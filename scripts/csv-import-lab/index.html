CSV Import Lab

Test bench for the CSV import MVP: one quick model call says whether a file is a training plan, a workout history or both (the "found data" screen), then the full import runs in the background (exercise mapping to the catalog, history, plan) and every call is timed. Everything runs in this browser; the key goes only to OpenAI.

On claude.ai this page can't call OpenAI or Supabase, so Mock model is on and the app's catalog is built in. For live runs with a key, open scripts/csv-import-lab/index.html from the repo on a computer.
